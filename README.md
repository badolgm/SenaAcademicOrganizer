## ✨ Visión

**SenaAcademicOrganizer** es más que un proyecto:  
es una apuesta por la **educación organizada, accesible y futurista**,  
donde la tecnología, la juventud y la ciencia se encuentran para **impulsar el aprendizaje**.

> _"Las estrellas no están lejos, son el mapa hacia el conocimiento."_ 🌌

### 🎯 **Sistema Revolucionario de Gestión Académica**

Diseñado específicamente para estudiantes del programa de **Análisis y Desarrollo de Software** del SENA (Ficha 3070388), este sistema combina:

- **🎨 Interfaz Futurista**: Primera experiencia visual inmersiva para portafolios académicos
- **🤖 Automatización Inteligente**: Organización automática basada en competencias SENA oficiales
- **🔗 Sistema Híbrido**: Script de escritorio + portafolio web para máxima flexibilidad
- **📊 Trazabilidad Completa**: Seguimiento detallado del progreso académico en tiempo real

## 🚀 Instalación Rápida

### **⚡ Opción 1: Clonar desde GitHub**
```bash
# Clona el repositorio oficial
git clone https://github.com/badolgm/SenaAcademicOrganizer.git

# Navega al directorio del proyecto
cd SenaAcademicOrganizer

# Abre el archivo principal en tu navegador
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### **🌐 Opción 2: Servidor Local**
```bash
# Con Python 3 (recomendado)
python -m http.server 8000
# Luego abre: http://localhost:8000

# Con Node.js (requiere instalación)
npx http-server
# Luego abre: http://localhost:8080

# Con PHP (si tienes XAMPP/WAMP)
php -S localhost:8000
```

### **☁️ Opción 3: Deploy Automático**
```bash
# Deploy en Netlify (gratis)
npm install -g netlify-cli
netlify deploy --prod

# Deploy en Vercel (gratis)
npm install -g vercel
vercel --prod

# Deploy en GitHub Pages (gratis)
# Solo haz push a la rama 'gh-pages'
```
